# 鬼哭街 原版阅读器

阅读 Nitroplus《鬼哭街》2002 原版（妹乃萌汉化，无语音）的桌面阅读器。中文横排，字体、字号、行距可调，背景音乐和音效随句子播放。

主要在 macOS 上开发和测试；基于 Go + [Wails](https://wails.io)，其他平台可自行构建尝试。

## 准备游戏数据

本程序不含任何游戏数据，请自备正版游戏和汉化补丁，放进 `~/Games/kikoku-2002/`。目录不对时，首次启动会让你选择文件夹。

| 文件 | 用途 | 必需 |
|---|---|---|
| `script.chs` | 中文剧本（汉化补丁） | ✓ |
| `IMAGE.PK2` | CG、背景、立绘 | ✓ |
| `SOUND.PK2` | 音乐、音效 | ✓ |
| `SCRIPT.PK2` | 日文剧本，用于修复汉化补丁中损坏的资源名 | 建议有 |
| `movie/*.mpg` | 过场动画 | 可选，需安装 [ffmpeg](https://ffmpeg.org) |

## 构建与运行

需要 Go 1.26+ 和 [Wails v2](https://wails.io/docs/gettingstarted/installation)。macOS 另需 Xcode 命令行工具。

macOS：

```bash
./build.sh
```

生成 `build/bin/kikoku2002.app`（已做本机签名），双击运行。

其他平台：

```bash
wails build
```

## 操作

| 按键 | 作用 |
|---|---|
| 点击 / 空格 / 回车 / 滚轮向下 | 下一句 |
| ← / 滚轮向上 | 上一句 |
| 右键 / H | 隐藏文字框 |
| 按住 Ctrl | 快进 |
| F | 全屏 |
| Esc | 菜单：字体、字号、行距、文字框浓度、音量、章节、过场 |

首次从头阅读会先播放开场动画，点击可跳过。设置和阅读进度自动保存。
